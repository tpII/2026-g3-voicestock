## Deviations

- The procedure's button sequence was not executed.
- `lgpio` was absent from the project virtual environment. The operating
  system already had `liblgpio1:armhf 0.2.2-1~rpt1+trixie`,
  `python3-lgpio 0.2.2-1~rpt1+trixie`, and
  `python3-rpi-lgpio 0.6-0~rpt1+trixie`. Those system packages did not
  make `lgpio` importable in `.venv`.
- Further diagnostics, reported with this attempt and not repeated as
  button samples: `/dev/gpiochip0`, `/dev/gpiochip1`, `/dev/gpiochip2`,
  and `/dev/gpiochip4` pointing at `gpiochip0`. The character devices were
  owned by `root:gpio` with group read/write. The executing user was in
  the `gpio` group. The system interpreter could `import lgpio`.
